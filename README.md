# bibliotecavd# 📚 Sistema de Gestão de Biblioteca Escolar

Sistema Web responsivo e integrado ao Google Sheets para controle de acervo, consultas, reservas de livros e notificações de devolução.

---

## ✨ Funcionalidades Principais

- **Consulta ao Acervo:** Busca de livros cadastrados em tempo real.
- **Login por Telefone/Perfil:** Acesso simplificado para alunos e professores.
- **Reserva de Livros:**
  - 📖 **Alunos:** Empréstimo por até 7 dias.
  - 🎓 **Professores:** Empréstimo estendido por até 15 dias.
- **Painel do Administrador:**
  - Cadastro rápido de livros via busca automática por **ISBN** (Google Books API).
  - Controle e atualização das quantidades de cópias disponíveis.
- **Lembretes Automáticos:** Envio de e-mails para os usuários avisando sobre prazos de devolução (via Google Apps Script).

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
- **Backend:** Google Apps Script
- **Banco de Dados:** Google Sheets (Planilhas do Google)
- **Hospedagem:** GitHub Pages
